🛠️ 1. Integrated Gherkin Checkers & Repositories

The suite processes every pasted or uploaded Gherkin file through 4 specialized checkers simultaneously:

1. gherkin-lint

github.com/gherkin-lint/gherkin-lint

Code quality linter enforcing indentation, duplicate scenario titles, missing descriptions, repeated keywords, and logical step order.

2. @cucumber/gherkin

github.com/cucumber/gherkin-javascript

Official Cucumber AST Parser validating token hierarchy, syntax correctness, tag syntax, tables, and document structure.

3. Matriz88/gherkin-checker

github.com/Matriz88/gherkin-checker

Consistency matcher validating dangling steps (And/But), unclosed quote literals, and verifying Scenario Outline <param> placeholders exist in Examples headers.

4. sistar/gherkin-validator

github.com/sistar/gherkin-validator

Lexical token scanner verifying table pipe alignments (|), column count mismatches across rows, and DocString block fencing (""").

📖 2. How to Use the Application

Step 1: Input Your Gherkin Feature Code

  • Paste Directly: Type or paste Gherkin text into the Gherkin Feature Editor.
  • Upload File: Click Upload File to select a .feature or .txt file.
  • 1-Click Presets: Test using 4 built-in preset test cases:
    • Valid Feature: Clean feature passing all 4 checkers.
    • Syntax & Lexing Errors: Demonstrates syntax and token failures.
    • Linter Rule Violations: Demonstrates duplicate scenario names & formatting warnings.
    • Inconsistent Steps: Demonstrates dangling steps & missing outline parameters.

Step 2: Real-Time Instant Analysis

The application runs all 4 checkers concurrently on every keystroke. Results update in < 5 milliseconds without requiring a manual submit button.

Step 3: Export Summary Reports

Export full analysis reports via the Download JSON Report or Download Markdown Report buttons.

🔍 3. How to Interpret Validations & Errors

Overall Pass / Fail Banner

PASS Displayed when 0 errors are found across all 4 checkers. Celebratory confetti triggers automatically.
FAIL Displayed when 1 or more errors are detected, showing total issue counts.

Detailed Failure Breakdown

Field Description Example Output
Line Number Exact line number in your .feature file Line 14
Category & Rule Categorized error badge & rule name [AST Syntax Error] / rule: parse-error
Failing Snippet Exact code text on that failing line | Laptop | 1000
Failure Reason Plain-English explanation of why it failed Table row must end with a pipe character "|".
Suggested Fix Step-by-step guidance on how to resolve it Add a trailing pipe "|" to close the table cell row on this line.

Editor Line Markers

  • Red circle markers highlight lines with critical errors.
  • Yellow warning triangles highlight quality warnings.
  • Clicking any error item in the dashboard scrolls and highlights the line in the editor.
